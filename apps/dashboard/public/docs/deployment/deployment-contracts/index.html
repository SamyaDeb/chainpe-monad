Contract Deployment

Step-by-step instructions for deploying ChainPe contracts to Fuji or Avalanche mainnet.

Prerequisites​

  • Node.js 18+
  • A funded deployer wallet (needs AVAX for gas; ~2 AVAX for full deployment)
  • DEPLOYER_PRIVATE_KEY set in .env
  • SNOWTRACE_API_KEY for verification (optional on Fuji, recommended for mainnet)

Environment setup​

cd contracts
cp ../.env.example .env
# Fill in DEPLOYER_PRIVATE_KEY, SNOWTRACE_API_KEY, OWNER_ADDRESS

Step 1: Deploy ERC-8004 registries​

npm run deploy:erc8004:fuji
# or for mainnet:
# OWNER_ADDRESS=0xYourSafe npm run deploy:erc8004:mainnet

Outputs addresses to contracts/deployments/fuji-erc8004.json.

Step 2: Deploy ChainPeRegistry​

npm run deploy:fuji
# or:
# OWNER_ADDRESS=0xYourSafe npm run deploy:mainnet

Uses the FEE_TOKEN_ADDRESS env var (defaults to the canonical USDC for the network):

  • Fuji: 0x5425890298aed601595a70AB815c96711a31Bc65
  • Mainnet: 0xB97EF9Ef8734C71904D8002F8b6Bc66Dd9c48a6E

REGISTRATION_FEE_USDC controls the fee (default: 1.0 USDC; Fuji is currently set to 0.1 USDC).

Outputs to contracts/deployments/fuji.json.

Step 3: Deploy PolicyVault​

npm run deploy:policyvault:fuji
# or:
# OWNER_ADDRESS=0xYourSafe npm run deploy:policyvault:mainnet

Outputs to contracts/deployments/fuji-policyvault.json.

Step 4: Deploy ICM contracts (optional)​

Required for cross-L1 payment intents:

npm run deploy:icm:fuji

Uses the canonical Teleporter address (0x253b2784c75e510dD0fF1da844684a1aC0aa5fcf).

Step 5: Verify on Snowtrace​

npm run verify:fuji
# or npx hardhat verify --network fuji <address> <constructor-args>

Step 6: Transfer ownership (mainnet only)​

SAFE_ADDRESS=0xYourGnosisSafe npm run transfer-ownership:mainnet

This initiates a two-step ownership transfer. The Safe must then call acceptOwnership() on each contract.

Step 7: Key safety check​

npm run check-keys

Verifies that deployer keys are distinct from operator keys and that no keys are in incorrect roles.

Hardhat configuration​

The hardhat.config.ts reads:

  • DEPLOYER_PRIVATE_KEY for signing transactions
  • FUJI_RPC_URL (default: https://api.avax-test.network/ext/bc/C/rpc)
  • AVALANCHE_RPC_URL (default: https://api.avax.network/ext/bc/C/rpc)
  • SNOWTRACE_API_KEY for Etherscan-compatible verification

Running contract tests​

cd contracts
npm test   # runs all 44+ tests with Hardhat and Mocha

All tests use MockUSDC and MockTeleporterMessenger — no real network required.
