# ChainPe on Monad

**The trust layer for x402 on Monad.** Fund an AI agent with an on-chain spending
mandate, let it pay any x402 API in USDC on Monad, and rank services by ERC-8004
reputation that only counts settled payments.

> **No receipt, no rating.**

🚧 **Status:** being built for the Monad Metropolis hackathon (Track 4 — Trust, Identity &
AI Infrastructure). See the build plan and the dated build log below.
